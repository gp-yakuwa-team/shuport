# プロンプトの配置

AI に渡すプロンプトは、ここに置く（詳細設計書 第6章 6.1）。

- フォルダはプロンプト番号ごと（P-01〜P-05）に分け、その下に版ごと（v1、v2、…）のフォルダを作る
- 各番号の用途とプロンプトの本文は、4.11 AIプロンプト設計詳細設計書が正本。ここには、4.11 で確定した本文だけを置く
- 本文は `{番号}/{版}/system.txt` に置く。入力はコードが封筒（task・schema_version・today_jst・input）にして末尾に付ける
- どの版を使うかの管理は config/ai.php の `prompts.versions` で行う
